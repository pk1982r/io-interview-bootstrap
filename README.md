# interview bootstrap

An example application built from the [ce3.g8 template](https://github.com/typelevel/ce3.g8).

## Purpose
To bootstrap a new Scala 3 application. Especially for interviews.  
To show best practices using non-trivial examples.

## How to use
Look for interesting technology and corresponding tests demonstrating how to use it.

## Run application
Running an application is also possible because this is another interview question.

Stage using sbt-native-packager
```shell
sbt stage
```
Go to the stage directory
```shell
cd target/universal/stage
```

Run executable
```shell
bin/io-interview-bootstrap
```
